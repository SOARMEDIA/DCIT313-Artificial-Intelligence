Getting started
1. Extract everything into ONE folder.
2. Open the notebook in Jupyter Notebook, JupyterLab, VS Code, or a compatible environment.
3. Set the notebook's working directory to that folder.
4. Execute the data-loading cells. Complete TODO exercises before running the assessment cells.
5. Submit a runnable notebook with outputs, the result table, explanation, tests,
   and disclosure of GenAI use (including no use where appropriate).

No API keys, payment, GPU, or external packages required. Python 3.10+ is sufficient.
All graph names, routes and numbers are purely synthetic classroom data.
